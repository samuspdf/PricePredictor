This project explores whether machine learning can predict short-term stock price movement using publicly available market data. Using daily SPY data (2015–2025) pulled via yfinance, I engineered technical features — returns, 5/20-day moving averages, 10-day volatility, and RSI(14) — to predict next-day price direction (up/down). A logistic regression baseline was evaluated against a naive "always up" benchmark, with class-weighting used to address class imbalance. The project includes a full write-up analyzing model performance, limitations, and what the results suggest about market efficiency at this timeframe.
